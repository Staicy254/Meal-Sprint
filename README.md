# Meal Thrift

Meal Thrift is a front-end food delivery application built with React, designed to provide users with an easy and efficient way to order food online. The application features a clean and minimalistic design, ensuring a seamless user experience.

## Features

- User-friendly interface for browsing food options
- Search functionality to find specific meals
- Add meals to cart for easy ordering
- Minimal and responsive design for mobile and desktop
- Smooth navigation between different sections of the app
